Chemical Reactions and Equations

TEAS objective S.3.3 · Chemistry

What the TEAS expects: you can read and balance a chemical equation, apply conservation of mass, and identify the main types of reactions.

1. Reading an equation

2H₂ + O₂ → 2H₂O

  • Reactants are on the left; products on the right. The arrow means "yields."
  • A subscript (the small 2 in H₂O) tells how many atoms of that element are in one molecule. It is part of the formula and can't be changed.
  • A coefficient (the big 2 in 2H₂O) tells how many molecules. It multiplies everything in the formula.
  • State symbols: (s) solid, (l) liquid, (g) gas, (aq) dissolved in water.

Counting atoms: 3H₂O contains 3 × 2 = 6 hydrogen atoms and 3 × 1 = 3 oxygen atoms.

2. Conservation of mass and balancing

Atoms are rearranged, never created or destroyed, in a chemical reaction. So the same number of each kind of atom must appear on both sides, and the total mass of products equals the total mass of reactants.

To balance an equation, change only the coefficients.

Worked example: __ CH₄ + __ O₂ → __ CO₂ + __ H₂O

  1. Carbon: 1 on each side. ✓
  2. Hydrogen: 4 on the left, so put 2 in front of H₂O (4 H).
  3. Oxygen: now 2 (in CO₂) + 2 (in 2H₂O) = 4 on the right, so put 2 in front of O₂.
  4. CH₄ + 2O₂ → CO₂ + 2H₂O. Check: C 1 = 1, H 4 = 4, O 4 = 4. ✓

Check 1: Balance: __ N₂ + __ H₂ → __ NH₃ Answer at the bottom of the page.

3. Types of reactions

Type Pattern Example
Synthesis (combination) A + B → AB 2Na + Cl₂ → 2NaCl
Decomposition AB → A + B 2H₂O₂ → 2H₂O + O₂
Single replacement A + BC → AC + B Zn + 2HCl → ZnCl₂ + H₂
Double replacement AB + CD → AD + CB (partners swap) AgNO₃ + NaCl → AgCl + NaNO₃
Combustion Fuel + O₂ → CO₂ + H₂O (+ energy) CH₄ + 2O₂ → CO₂ + 2H₂O
Neutralization (a double replacement) Acid + base → salt + water HCl + NaOH → NaCl + H₂O

Memory hook: synthesis builds one product; decomposition breaks one reactant; single replacement has one lone element on each side; double replacement swaps partners like a square dance.

4. Energy in reactions

  • Exothermic reactions release energy (heat or light) to the surroundings; the surroundings get warmer. Burning and cellular respiration are exothermic.
  • Endothermic reactions and processes absorb energy; the surroundings get colder. Photosynthesis is endothermic, and so is the dissolving inside an instant cold pack.
  • Oxidation is the loss of electrons; reduction is the gain of electrons. They always happen together (redox). Memory hook: OIL RIG (Oxidation Is Loss, Reduction Is Gain).

Check 2: An instant cold pack gets cold when squeezed. Is the process inside exothermic or endothermic? Answer at the bottom of the page.

Common traps

  • Changing subscripts to balance. That changes the substance itself (H₂O to H₂O₂ is a different chemical).
  • Forgetting to multiply the coefficient through. 2H₂O has 4 H, not 2.
  • Mixing up synthesis and decomposition. Check which side has the single compound.
  • Thinking mass is lost when a gas escapes. It isn't lost; it just leaves an open container.
